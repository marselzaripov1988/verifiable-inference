# Проверяемый инференс: протокол, шлюз, замеры

Протокол, в котором посторонний владелец видеокарты выполняет запросы к
языковой модели за плату, а сеть может **поймать его на подлоге** —
подмене модели, квантования или рантайма — не повторяя работу целиком.

Проверка стоит 9,7% от порождения при четырёх проверяющих, а не 400%,
потому что проверяющий не порождает ответ заново: он оценивает готовый
текст одним проходом и сравнивает вероятности со своими.

## Почему этот репозиторий отдельный и почему он должен быть читаемым

Вся конструкция держится на одном: исполнитель ставит залог, а сеть
сравнивает расхождение с порогом **0,0360**. Если порог, контракт и
правило вердикта закрыты, посторонний ставит залог на веру, и ни
обязательства, ни споры, ни конфискат ничего не добавляют. **Проверяемый
инференс, который нельзя проверить, — противоречие.** Поэтому здесь
лежат и код, и замеры, которыми порог получен.

## Что здесь

| Каталог | Что внутри |
|---|---|
| `protocol/` | контракт CosmWasm, демоны исполнителя и проверяющего, правило вердикта |
| `gateway/` | шлюз этапа 1: приём запроса, оплата, отдача ответа, без проверок |
| `research/inference-determinism/` | замеры, которыми получен порог, вместе с сохранёнными векторами |
| `research/migrate-rollback/` | опыт на девнете: перенос состояния сохраняет всё, откат на прежний код невозможен |
| `research/axiome-devnet/` | стенд с исправленным узлом Axiome: три правки, проверенные исполнением, и отрицательный контроль на выпуске |

Проверить всё, не веря ни одному утверждению на слово:

```sh
python protocol/test_verify.py                 # правило на сохранённых векторах
python protocol/daemon/test_canon.py           # канон кодирования
python protocol/daemon/test_daemons.py         # демоны
python protocol/daemon/test_loop.py            # петля узла
python protocol/daemon/test_client.py          # заказчик
python -m unittest discover -s gateway/tests   # шлюз
docker run --rm -v "$PWD/protocol/contract:/w" -w /w rust:slim cargo test
sh protocol/devnet/run.sh                      # полный цикл на настоящем wasmd
sh protocol/devnet/run-loop.sh                 # заказчик и три узла, без человека
```

`test_verify.py` не выдумывает данные: он берёт сохранённые векторы
вероятностей из `research/inference-determinism/results/` и требует,
чтобы правило дало на них те же числа, что опубликованы.

## Четыре числа, на которых всё стоит

| Величина | Значение | Откуда |
|---|---|---|
| порог расхождения | 0,0360 | середина зазора по логарифму |
| честное расхождение | 0,01270 среднее, 0,04466 худшее | 1520 наблюдений на одной карте |
| подлог FP8, самый незаметный | 0,03778 | минимум из измеренных |
| межкарточное честное | 0,01295–0,01330 среднее, 0,02014 худшее | A100 и 3090 против 4090, 14 октября 2026 |

Последняя строка — единственная, снятая **тем же кодом, которым считает
проверяющий**, а не измерительной оснасткой. Она же показала, что
ограничение длины ответа (32 токена) несущее: все честные превышения
порога пришлись на ответы в 5–25 токенов.

## Чего здесь нет

- **Форка Artery и переезда на SDK 0.53.** Протокол нельзя написать
  контрактом на сегодняшней Artery: контракт там спрашивает
  `cosmos.bank`, а сеть отдаёт `artery.bank`, поэтому он принимает
  монеты и не может отправить. Протокол нацелен на Axiome, где банк
  стандартный, а CosmWasm заведён на самом деле.
- **Проверки хранения.** Память — другая задача по существу: нужны
  доказательства хранения, а не порог расхождения. Ни 0,0360, ни четыре
  проверки к ней не относятся.
- **Спроса.** Нужен ли этот протокол кому-нибудь — отвечает шлюз этапа 1,
  а не код протокола.

## Что в нём ещё не решено

Доставка вектора проверяющим (сейчас файл; в цепочке только хэш, и это
правильно) и привязка допуска к реферальной структуре: контракту не видна
структура Axiome, потому что из набора возможностей wasm вырезан
`stargate`. Доверенную сторону, которая подтверждала допуск подписью, из
контракта 26 октября убрали — допуск теперь залог плюс проба, то есть то,
что цепочка проверяет сама. Привязка к структуре вернётся, если площадка
даст `stargate`.

Решено с тех пор: кто платит проверяющим — заказчик, сверх цены. И где
брать текст: адреса доставки лежат в цепочке — у задания `prompt_uri`, у
узла `endpoint`, — а не передаются людьми. Доверия это им не даёт, решает
по-прежнему хэш. В живой цепочке с 28 октября: три экземпляра на
`code_id` 342 ([protocol/РАЗВЁРТЫВАНИЕ.md](protocol/РАЗВЁРТЫВАНИЕ.md)).
