# Проверка запуска на настоящей карте, 29 октября 2026

`start.sh` прогнан на арендованной RTX 4090 (Эстония, драйвер 580.178.04)
против тестового экземпляра реестра. Проверялась логика запуска: порядок
шагов, признаки и отказы.

## Прошло

| Шаг | Признак |
|---|---|
| 0 | заданы реестр и адрес доставки |
| 1 | `NVIDIA GeForce RTX 4090, драйвер 580.178.04 → класс sm_89` — класс выведен из МОДЕЛИ карты |
| 2 | класс реестра из цепочки совпал: `sm_89` |
| 3 | `кеш sm_89 на месте, 21 МБ, sha256 сошёлся` |
| 4 | сервер ответил `0.31.0`, и **ноль** строк `Compiling a graph` — кеш принят |
| 5 | проба пройдена: расхождение 0 по 34 текстам |
| 6 | ключ внесён, рабочий адрес напечатан |
| 7 | раздача связок отвечает |
| 8 | петля пошла и **сама объявила адрес**: `в цепочке http://10.0.0.1:1111, у нас http://194.126.112.5:16290 — объявляем` |

Затем заказчик поставил задание 3, и узел, поднятый только этим
скриптом, взял его и сдал ответ:

```
3: claim_job — свободное задание, своего нет
3: answer — своё взятое задание без ответа
3: запрос получен из http://194.126.112.5:15663/bd49d6d0….txt, сошёлся с цепочкой
```

Связка проверена **снаружи**, с другой машины: по объявленному адресу
`http://194.126.112.5:16290/3.json` лежит ответ 456 символов и вектор 223
элемента, оба хэша сошлись с заданием в цепочке.

## Отказы — такой же признак

| Условие | Отказ |
|---|---|
| нет `CONTRACT` | `нужен CONTRACT=axm1…` |
| нет `ENDPOINT` | `нужен ENDPOINT=…`, и сказано, почему его не вывести изнутри |
| `ENDPOINT` без схемы | `должен начинаться с http:// или https://` |
| реестр ДРУГОГО класса (3090) при карте 4090 | `у реестра класс sm_86, а карта sm_89` — сверка с цепочкой |

## Что прогон нашёл

**Ключ не вносился при повторном запуске.** `axmd keys import-hex` падает,
если имя в связке уже есть, а связка живёт в `$NODE_HOME`, который бывает
томом. Запуск вставал на шаге 6, и причина в журнал не попадала: в скрипте
стоял `2>/dev/null`. Исправлено: прежняя запись сносится, а ошибка импорта
теперь печатается.

## Чего эта проверка не покрыла

- **Сам `Dockerfile` не собран.** Локальная сборка умерла на скачивании
  базового слоя: на машине осталось 7 ГБ при 111 ГБ, занятых данными
  Docker. Проверена вся логика `start.sh` и установка официальных
  бинарей теми же командами, что в `Dockerfile` (`axmd` и `libwasmvm`,
  обе суммы сошлись), но не сборка образа как таковая.
- **Отказ без карты** — на хосте карта есть, этот путь остался
  непроверенным.
- **Вердикт** — узел был один, а проверок нужно две. Задание 3 осталось в
  `answered`; его закроет `expire_checks` через час после сдачи, вернув
  деньги заказчику. До тех пор залог узла `axm1fvfv…u7jx` заперт
  незакрытым заданием — это и есть штатное поведение, см. раздел 8
  инструкции.
