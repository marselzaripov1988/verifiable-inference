# Узел одним образом

Сборка, в которой уже лежит всё, кроме двух значений: ключа и адреса.
Инструкция целиком — [../УЗЕЛ.md](../УЗЕЛ.md); здесь то, что образ
заменяет собой.

## Что внутри и чего нет

| | |
|---|---|
| база | `vllm/vllm-openai:v0.31.0` — 10,1 ГБ сжатым, пинованная версия: ровно та, на которой снят эталон |
| кеш ядер | все три класса, по 2,4 МБ архивом; распаковывается **до** первого запуска сервера, класс выбирается по карте |
| демоны и эталоны пробы | `daemon/` без тестов |
| `axmd` | официальный выпуск Axiome v2.2.1, сверяется по sha256 при сборке |
| `libwasmvm` | официальный выпуск CosmWasm v1.5.0, сверяется по их `checksums.txt`. Без неё `axmd` не стартует вовсе |
| **весов модели нет** | 15 ГБ, которые качаются с HuggingFace за 1–3 минуты (замерено 29 октября на трёх арендованных картах). Запекать их — утроить образ ради того, что и так быстро |

## Взять готовый

```sh
docker pull ghcr.io/marselzaripov1988/verifiable-inference-node:v1
```

Выложен 29 октября 2026 сборкой в GitHub Actions, digest:

```
sha256:672a88a7129065b5c495398c18843cd6e28dacc62ecf1ca14fc59197a1826df9
```

Этот digest и есть то, на что стоит ссылаться: тег `v1` можно
переписать, digest — нет. Образ собран из коммита `c3e2324`, и перед
выкладкой на нём проверены признаки — `axmd` запускается, демоны
импортируются, кешей ядер три, четыре отказа отвечают по делу. Сборка,
не прошедшая проверки, до реестра не доходит.

## Собрать самому

Нужно **32,5 ГБ** свободного места: именно столько занимает
распакованный образ (замерено сборкой, а не прикинуто). На машине с 21 ГБ
свободного сборка дважды забила диск и уронила движок Docker — отсюда и
сборка в Actions, где диск чужой и шаг очистки сносит с раннера .NET,
Android SDK и GHC.

Суммы обязательны: без `AXMD_SHA256` сборка отказывается, чтобы в образ
не попал непроверенный бинарь, которым подписываются сделки с залогом.

```sh
docker build -f protocol/node-image/Dockerfile -t inference-node \
  --build-arg AXMD_SHA256=c8ef347f91b1378225f102c1124efcdc81fe6bb83ae2223fd8175df2041c0d4d \
  protocol/
```

Суммы на 29 октября 2026: `axmd-linux-amd64-2.2.1` —
`c8ef347f…1c0d4d`, `libwasmvm.x86_64.so` v1.5.0 —
`372c4fe9…2ababf` (вторая прибита в `Dockerfile`).

## Запустить

```sh
docker run -d --gpus all --name node \
  -p 8081:8081 \
  -e CONTRACT=axm1fe5dsxm3vcnwjkvlgjk9mkvqnl6ggpay3y3r94hls7g3hz4s68tqcp547r \
  -e ENDPOINT=http://ВАШ-АДРЕС:ПОРТ \
  -e KEY_HEX=<64 знака рабочего ключа> \
  inference-node
```

Три значения, и каждое нужно по делу:

- **`CONTRACT`** — реестр своего класса. Образ один на три класса, и он
  сверяет: класс карты обязан совпасть с классом реестра, иначе отказ до
  всякой работы.
- **`ENDPOINT`** — адрес, по которому связки видно **снаружи**. Изнутри
  его не определить: на арендованных машинах наружу смотрит другой порт
  (у нас выходили 29317, 20153, 23569), и узел не достаёт сам себя даже
  по своему публичному адресу — NAT не разворачивает пакет. Это и есть
  причина, по которой «ввести только ключ» не выходит.
- **`KEY_HEX`** — ключ **рабочего** адреса, не того, где залог. Как
  развести их так, чтобы украденный рабочий ключ не увёл залог, — раздел
  9 в [../УЗЕЛ.md](../УЗЕЛ.md); проверено на живой цепочке.

Прочее переопределяется при надобности: `REST`, `RPC`, `CHAIN_ID`,
`GAS_PRICES` (по умолчанию `0.0025uaxm` — цепочка принимает), `MODEL`,
`MAX_TOKENS`, `EVERY`, `MIN_LEFT`.

## Признаки, по которым видно, что всё хорошо

Запуск печатает восемь шагов, у каждого свой признак:

1. заданы `CONTRACT` и `ENDPOINT`, адрес начинается с `http`;
2. карта опознана и класс выведен из **модели**, а не архитектуры;
3. класс реестра из цепочки совпал с классом карты;
4. `sha256` архива кеша сошёлся, кеш распакован;
5. сервер отвечает `0.31.0`, и в журнале **ноль** строк
   `Compiling a graph` — главный признак, что кеш принят;
6. проба: расхождение **0** по 34 текстам;
7. ключ внесён, рабочий адрес напечатан;
8. раздача связок отвечает 200, дальше работает петля.

Любой шаг, не давший признака, останавливает запуск с отказом, в котором
сказано, что делать. Пустой вывод успехом не считается.

## Чего образ не делает

- **не вносит залог и не регистрирует узел.** Это три сделки с холодного
  адреса (разделы 5 и 8 инструкции), и делать их из контейнера на
  арендованной машине незачем — там не должно быть ключа с залогом;
- **не проверяет, что ваш `ENDPOINT` достижим.** Узел не может этого
  изнутри; проверять надо снаружи, иначе ваши ответы никто не проверит и
  задание закроется сроком без оплаты;
- **не хранит ключ зашифрованным.** Связка `axmd` в контейнере
  незашифрованная, и это сознательный выбор: иначе узел не поднимется сам
  после перезагрузки. Поэтому ключ — рабочий, а не залоговый.
