# Вечерние часы сети

Три узла на RTX 4090 работают каждый день с 19:00 до 21:00 по Москве.
Расписание ведёт сервер (cron), машины арендуются на vast.ai.

| Время (МСК) | Что делается |
|---|---|
| 18:20 | `vecher.py up`: остановленные машины запускаются; если карту заняли — арендуется другая 4090 не дороже `max_dph`. На машину по stdin ssh уезжает ключ, запускается `start.sh`, ждём петлю |
| 21:00 | `vecher.py down`: до 10 минут ждём, пока взятые и неоплаченные задания закроются, стираем ключ с машины и **останавливаем** её |
| 21:30 | `vecher.py down --no-drain`: страховка, если в 21:00 что-то не остановилось |

Залог (0,3 BARTR на узел) вносится один раз (`vecher.py stake`) и не
снимается: выключенный узел заданий не берёт, а брошенное задание
контракт возвращает в очередь без наказания.

**Вопросы вне часов** никто не возьмёт: они ждут до 19:00 следующего дня
или пока заказчик не отменит. Бот должен говорить об этом сам.

## Цена

4090 на vast.ai стоит $0,47–0,54 в час (замер 10 ноября 2026). Три карты
по ~2,5 часа — около $4 в день, $115–120 в месяц, плюс хранение дисков
остановленных машин.

## Установка на сервер

```bash
apt-get install -y python3-venv
python3 -m venv /opt/vecher/venv && /opt/vecher/venv/bin/pip install vastai==1.8.3
/opt/vecher/venv/bin/vastai set api-key <ключ>       # ключ API vast.ai
install -m 700 -d /opt/vecher/keys                    # node1.key … node3.key, права 600
cp vecher.py /opt/vecher/ && chmod +x /opt/vecher/vecher.py
cp vecher.example.json /opt/vecher/vecher.json
cp vecher.cron /etc/cron.d/vecher
```

Открытый ключ ssh сервера (`~/.ssh/id_ed25519.pub`) должен быть в аккаунте
vast.ai: машины создаются с ключами аккаунта.

Журнал: `/var/log/vecher.log`. Состояние (номера машин): `/opt/vecher/state.json`.

## Чего скрипт не делает

- Не следит за машиной в течение двух часов. Если прерываемую или
  обычную машину остановит хозяин, узел до конца вечера не вернётся.
- Не меняет бота: часы работы бот пока не объявляет.
- Не пополняет газ: при остатке ниже `--min-gas` петля предупреждает в
  своём журнале на машине.
