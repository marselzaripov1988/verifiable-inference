# Как развернуть кабинет узла в Telegram

Инструкция для того, кто поднимает кабинет на сервере и подключает его к
боту. Что такое кабинет и как он устроен — [README.md](README.md).

**У каждого шага есть признак.** Отсутствие ошибки признаком не считается.

## Что нужно заранее

| Что | Где взять |
|---|---|
| сервер Linux (Ubuntu 22.04+) с публичным IP | лучше тот же, где работает бот `protocol/telegram/bot.py`: тогда кабинет пишет подписки прямо в его базу |
| домен или поддомен, например `cabinet.example.org`, A-запись на IP сервера | у регистратора домена |
| открытые порты 80 и 443 | нужны Caddy, чтобы получить сертификат |
| Python 3.10+ и git | `apt install python3 git` |
| токен бота, в котором будет открываться кабинет | у владельца бота, из @BotFather |
| путь к базе бота `bot.sqlite`, если бот на этом сервере | из настроек бота (`DB`) |

Кабинет не держит ни ключей, ни денег. Сделки подписывает сам владелец
узла в Axiome Wallet. Секрет здесь один — токен бота.

## 1. Забрать код

```sh
sudo git clone https://github.com/marselzaripov1988/verifiable-inference /opt/verifiable-inference
cd /opt/verifiable-inference
git checkout node-cabinet      # пока PR не слит в main; после слияния — main
```

Зависимостей нет, только стандартная библиотека Python.

**Признак:** `python3 protocol/cabinet/test_cabinet.py` заканчивается
строкой `кабинет ведёт себя как задумано`.

## 2. Проверить на месте, без Telegram

```sh
DEV=1 PORT=8095 DB=/tmp/cab-test.sqlite python3 -u protocol/cabinet/server.py
```

**Признак:** четыре строки `реестр axm1…: RTX 4090 / RTX 3090 / RTX 5090 /
RTX 4090`. Если вместо карты написано `timed out`, LCD не ответил;
перезапустите позже или проверьте сеть сервера. Остановить — Ctrl+C.

`DEV=1` пускает без Telegram. **В работе его не включать.**

## 3. Настройки и служба

Файл с секретом:

```sh
sudo tee /etc/vi-cabinet.env >/dev/null <<'EOF'
TG_TOKEN=123456789:AA...токен бота...
BOT_DB=/путь/к/bot.sqlite
DB=/var/lib/vi-cabinet/cabinet.sqlite
HOST=127.0.0.1
PORT=8095
EOF
sudo chmod 600 /etc/vi-cabinet.env
sudo mkdir -p /var/lib/vi-cabinet
```

Если бот на другом сервере, строку `BOT_DB` уберите: кабинет будет
работать, только без уведомлений об узлах.

Служба systemd:

```sh
sudo tee /etc/systemd/system/vi-cabinet.service >/dev/null <<'EOF'
[Unit]
Description=Кабинет узла (Telegram Mini App)
After=network-online.target

[Service]
EnvironmentFile=/etc/vi-cabinet.env
WorkingDirectory=/var/lib/vi-cabinet
ExecStart=/usr/bin/python3 -u /opt/verifiable-inference/protocol/cabinet/server.py
Restart=always
RestartSec=5
# Тот же пользователь, под которым работает бот: иначе нет права писать в BOT_DB
User=root

[Install]
WantedBy=multi-user.target
EOF
sudo systemctl daemon-reload
sudo systemctl enable --now vi-cabinet
```

**Признак:** `journalctl -u vi-cabinet -n 20` показывает четыре строки
`реестр …` и `кабинет: http://127.0.0.1:8095/`. Затем
`curl -s localhost:8095/api/me` отвечает
`{"error": "нет initData: откройте кабинет из Telegram"}`. Это
правильно: без Telegram API закрыт.

## 4. HTTPS

Telegram открывает мини-приложения только по `https://`. Ставим Caddy,
сертификат он получит сам:

```sh
sudo apt install -y caddy
sudo tee /etc/caddy/Caddyfile >/dev/null <<'EOF'
cabinet.example.org {
    reverse_proxy 127.0.0.1:8095
}
EOF
sudo systemctl reload caddy
```

**Признак:** `https://cabinet.example.org/` в обычном браузере
открывает страницу «Узлы проверяемого инференса». Список узлов покажет
ошибку «откройте кабинет из Telegram» — так и должно быть.

Если на сервере уже стоит nginx, достаточно `proxy_pass
http://127.0.0.1:8095;` в блоке `server` с действующим сертификатом.

## 5. Подключить к боту

Всё в @BotFather, для **того же бота, чей токен в `TG_TOKEN`**. Подпись
`initData` делается токеном бота, из которого открыт кабинет. Если боты
разные, кабинет отвечает «подпись initData не сошлась».

**Кнопка меню.** Слева от поля ввода в чате с ботом:

1. `/mybots` → бот → **Bot Settings** → **Menu Button** → **Configure menu button**.
2. Прислать URL: `https://cabinet.example.org/`.
3. Прислать название: `Кабинет узла`.

**Мини-приложение по ссылке.** Нужно, чтобы открывать кабинет из
«Кубика»:

1. `/newapp` → выбрать бота.
2. Название `Кабинет узла` и описание.
3. Картинка 640×360. Gif можно пропустить: `/empty`.
4. URL: `https://cabinet.example.org/`.
5. Короткое имя, например `node`.

BotFather выдаст ссылку `https://t.me/<имя_бота>/node`.

**Признак:** в Telegram кнопка меню или ссылка открывают кабинет. Во
вкладке «Подключить» видны карты RTX 4090 / 3090 / 5090. Добавленный в
«Мои узлы» адрес через несколько секунд показывает статус и заработок.

## 6. Встроить в «Кубик»

Если «Кубик» — сам мини-приложение Telegram, кнопка «Подключить ноду»
открывает кабинет так:

```js
Telegram.WebApp.openTelegramLink("https://t.me/<имя_бота>/node");
```

Если «Кубик» — бот, хватит кнопки со ссылкой
`https://t.me/<имя_бота>/node` или кнопки `web_app` с URL
`https://cabinet.example.org/` (а тогда `TG_TOKEN` — токен бота
«Кубика»).

**Уведомления** об узлах шлёт бот `protocol/telegram/bot.py`. Он может
писать человеку только после того, как тот хоть раз нажал у него
«Старт». Если кабинет открыт из другого бота, попросите людей запустить
и нашего бота.

## 7. Проверка всей цепочки

Возьмите адрес узла, который точно работает, например любой
`executor` из заданий боевого реестра 4090. Добавьте его в «Мои узлы» и
откройте. Должно быть:

- балансы AXM и BARTR — числа, а не «—»;
- «RTX 4090», залог 1 000 BARTR, «Заработано» больше нуля;
- зелёные шаги «Записан», «Залог», «Проба», «Адрес объявлен».
  «Адрес отвечает» зелёный только в часы работы узлов (19:00–21:00 МСК);
- «Внести» → «Скопировать строку для Axiome Wallet» копирует строку,
  начинающуюся с `axiomesign://`.

Подписывать её не нужно: это была бы настоящая сделка.

## Обновление

```sh
cd /opt/verifiable-inference && sudo git pull && sudo systemctl restart vi-cabinet
```

Данные (`/var/lib/vi-cabinet/cabinet.sqlite`) при обновлении не
трогаются.

## Если что-то не так

| Что видно | Что это |
|---|---|
| «нет initData: откройте кабинет из Telegram» | открыто в обычном браузере, а не в Telegram |
| «подпись initData не сошлась» | в `TG_TOKEN` токен не того бота, из которого открыт кабинет |
| «initData устарел» | кабинет открыт больше суток назад: закрыть и открыть заново |
| реестр с `timed out` в журнале | LCD `axm-lcd.trickle.pro` не ответил; кабинет повторит сам через 5 минут |
| заработок 0 сразу после запуска | задания реестров читаются при старте, это до минуты |
| «подписка бота не записана» в журнале | у службы нет права писать в `BOT_DB`: запускайте под пользователем бота |
| Telegram не открывает ссылку | URL не `https://` или сертификат не получен: смотрите `journalctl -u caddy` |
