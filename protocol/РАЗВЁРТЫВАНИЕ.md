# Развёртывание реестра в axiome-1

Лист параметров: [`contract/deploy/instantiate.json`](contract/deploy/instantiate.json).
Он **проверяется тестом** — разбирается в `InstantiateMsg` и сверяется с
измеренными числами, — поэтому разойтись с контрактом молча не может.

## Что уже решено

| Параметр | Значение | Откуда |
|---|---|---|
| `threshold_micro` | 36000 | середина зазора по логарифму |
| `checks_required` | 4 | замер |
| `min_answer_tokens` | 32 | ниже запас падает до 1,6×, и честные превышения порога пришлись на ответы в 5–25 токенов |
| связка | Qwen2.5-7B-Instruct / vllm-0.31.0 / bfloat16 | для неё измерен порог |
| `conformance_limit_micro` | 60000 | три честных наблюдения (19 656, 20 137, 22 421) против неверного режима 410 012 |
| `conformance_ref_hash` | `ed6a265b…a7da2b1` | `daemon/probe/probe.json`, 34 текста |
| `settlement` | `{"native":"uaxm"}` | шлюз этапа 1 собирает AXM; одна монета на оба этапа |
| `stake_denom` | `uaxm` | сжигание родной монеты — настоящая стока |
| `min_stake` | 30 400 AXM | нижняя граница замера ($38 при курсе $0,00125) |
| `verifier_fee_bps` | 970 | замеренные накладные при четырёх проверках |
| `forfeit` | `ToAddress` | `BankMsg::Burn` доказан на wasmd 0.50.0, но **на самой Axiome не проверен** |

## Чего не хватает: два адреса

1. **`admin` и `attestor`** — ваш адрес. `attestor` подтверждает допуск
   исполнителя: контракту не видна реферальная структура Axiome, потому
   что из набора возможностей wasm вырезан `stargate`. Это честная
   заглушка под ограничение площадки, а не решение задачи допуска.
2. **`forfeit.to_address`** — куда уходит изъятый залог.

**Про второй адрес стоит подумать отдельно.** Если конфискат идёт на тот
же адрес, что и `attestor`, то сторона, которая **допускает**
исполнителей, на их осуждении **зарабатывает**. Контракт намеренно не
имеет варианта «проверяющим» ровно по этой причине — платить обвинителям
значит создать интерес обвинять. Адрес администратора эту проблему
смягчает, но не снимает.

Разумные варианты: отдельный адрес общего пула, которым не распоряжаются
единолично; либо `Burn` — после того как он будет проверен на самой
Axiome одной живой конфискацией.

## Одно следствие, которое надо знать до развёртывания

**Долю проверяющих платит исполнитель, а не заказчик.** В коде
`rest = price - fees`, и исполнителю достаётся остаток: заказчик платит
цену целиком, исполнитель получает её минус 9,7%. Это не настройка — это
то, как считает `finalize`. Чтобы долю платил заказчик, он должен был бы
переводить `цена × (1 + bps)`, а это правка контракта.

## Загрузка кода разрешена всем

Проверено запросом к цепочке: `code_upload_access` — `Everybody`, и оба
контракта BARTR загружены обычным аккаунтом. Голосование не нужно.

## Команды

```sh
# 1. собрать артефакт (воспроизводимо из Cargo.lock)
docker run --rm -v "$PWD/protocol/contract:/code" \
  -v registry_cache:/usr/local/cargo/registry cosmwasm/optimizer:0.16.0

# 2. загрузить код
axmd tx wasm store protocol/contract/artifacts/inference_registry.wasm \
  --from ВАШ_КЛЮЧ --chain-id axiome-1 --gas auto --gas-adjustment 1.3 -y

# 3. развернуть: подставьте адреса в листе и разверните им
axmd tx wasm instantiate <CODE_ID> "$(cat protocol/contract/deploy/instantiate.json)" \
  --label inference-registry --admin ВАШ_АДРЕС \
  --from ВАШ_КЛЮЧ --chain-id axiome-1 --gas auto --gas-adjustment 1.3 -y

# 4. признак успеха: настройки читаются из цепочки и те самые
axmd query wasm contract-state smart <АДРЕС_КОНТРАКТА> '{"config":{}}' -o json
```

Признак успеха шага 4 — не отсутствие ошибки, а совпадение: в ответе
`threshold_micro` = 36000, `conformance_limit_micro` = 60000 и
`conformance_ref_hash` = `ed6a265b…`. Если эталон в цепочке разойдётся с
`daemon/probe/probe.json`, узлы будут считать пробу против одного набора,
а контракт ждать другого — и честный узел получит отказ.

## После развёртывания

1. Каждый узел проходит пробу: `python3 conformance.py --rest … --contract …`
   и отправляет полученное сообщение `submit_conformance`.
2. Исполнитель вносит залог и получает допуск от `attestor`.
3. Задание ставится `SubmitJob` с монетой, и дальше — обычный цикл.

Полный цикл в этом порядке пройден на девнете wasmd 0.50.0 с libwasmvm
1.5.0 — той же паре, что у Axiome: `devnet/run.sh`, четырнадцать шагов.
